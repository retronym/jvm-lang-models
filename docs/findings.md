# Findings register

Findings that need a decision: a compiler or tool behaviour the models or probes turned up that may be a bug, a spec gap or a deliberate choice. Each row says where the evidence is and what would move it on. Add a row in the same commit as the work that found it; when a finding is filed, record the link and move it to **filed**; when it is decided, record the decision under *Decided*.

Statuses: **triage** (not yet judged: bug, spec gap or by design?), **draft** (a report is written in [`upstream/`](upstream/README.md), not posted), **filed**, **fixed on a branch** (a fix exists, not merged), **known** (already reported upstream; ours adds evidence), **no action** (by design, recorded for understanding).
